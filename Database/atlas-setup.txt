MongoDB Atlas Setup Steps

1. Create a free MongoDB Atlas account.
2. Create a new cluster.
3. Create a database user with username and password.
4. In Network Access, allow your current IP address.
5. Click Connect.
6. Choose Drivers.
7. Copy the connection string.
8. Replace username, password, and database name in the string.
9. Open Backend/.env.
10. Paste the final string in MONGODB_URI.

Example format:
mongodb+srv://username:password@cluster-url/healthcampdb?retryWrites=true&w=majority

After that run:
- npm start
