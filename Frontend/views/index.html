System Flow

This page is only visible after login. The cards below are shown according to the logged-in user role.

  • Admin creates a camp and adds doctors.
  • Volunteer registers a patient and gets a token number.
  • Doctor views pending patients and updates diagnosis.
  • Admin checks reports and exports data.

Project Focus

This application demonstrates CRUD operations, relationships, search, filters, reporting, and data export using a simple stack.
